How the test runs:

- The shop is Medusa 2.22.0 with its default settings.
- A test starts one or two Medusa servers that share one database.
- Every run starts from a fresh database with the seeded products and stock described in the scenario format below.
- Each attempt runs several times, and every run is judged by every check in the check rules below.
- The source code you can read is Medusa 2.22.0's packages folder, without its Enterprise Edition files.
